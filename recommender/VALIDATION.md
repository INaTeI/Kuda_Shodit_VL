# Проверка Qwen

13 ноября 2026 года на macOS, Python 3.12.16, PyTorch 2.11.0, CPU:

- Каталог: 188 мест, уникальные ID и согласованные файлы данных.
- Qwen3-Embedding-0.6B загружается из models/qwen без интернета.
- Шесть интеграционных тестов API прошли с реальными весами.
- Проверены подбор боулинга, исключения ID, бюджет, валидация,
  похожие места, ограничение типа и ошибки 404/422.
- Docker Compose: конфигурации CPU и GPU проходят config --quiet.
- Сборка контейнера и работа на сервере пока не проверены.

В проекте оставлена только Qwen. Веса и кэш исключены из Git.

## Экспериментальная адаптация запросов, 13 ноября 2026

- На CPU обучена остаточная ridge-проекция над замороженными векторами Qwen:
  64 синтетических обучающих запроса, 16 validation, 16 test.
- Релевантность — слабая разметка по типам/тегам того же каталога, не оценки людей.
  NDCG@5 на test: 0.6373 → 0.8949. Это не доля правильных ответов.
- Добавлена строгая категория прогулки; исправление фильтра отдельно от обучения.
- С адаптером прошли 11 тестов (8 API и 3 проверки адаптера), без адаптера — 8 API-тестов.
- Через HTTP проверены готовность, пользовательский запрос «хочу сходить погулять»
  и похожие на «Поэма вкуса» места. В прогулке возвращены только скверы;
  в похожих — кофейни. Результаты: `data/training_smoke.json`.
- Отчёт и отдельные запросы до/после: `data/adapter_report.json`.
- Исходные веса не изменены. Адаптер опционален через `QUERY_ADAPTER_PATH`.
- Качество на реальных пользовательских оценках и новых местах не проверено.
- Метод: https://www.sbert.net/docs/sentence_transformer/training_overview.html
  (разделение обучения и оценки); Qwen: https://huggingface.co/Qwen/Qwen3-Embedding-0.6B.

## Исправления по результатам ML-аудита, 13 ноября 2026

- Основной serving возвращён к базовому Qwen. Одного QUERY_ADAPTER_PATH недостаточно
  для эксперимента: требуется QUERY_ADAPTER_MODE=experimental и прошедший проверку NPZ v2.
- Добавлены строгие типы SUP, бассейн и еда. Одна явная верхняя граница в рублях
  распознаётся из query при отсутствии budget; явные поля сохраняют приоритет.
- Точное название не превращается в категорию. Проверены все 188 названий через
  полный метод подбора: каждое место оказалось первым. Проверены исключения ID.
- Исправлены перезапись артефактов и совместимость по mtime. Проверки охватывают
  одинаковое содержимое с разными временами файлов, изменение весов, prompt и длины.
- Обучение с новым регрессионным набором завершилось кодом 2: кандидат ухудшил
  запрос про животных и отклонён. Это ожидаемый отказ допуска, не успешный релиз.
  Результат — data/adapter_report_v2.json; файл кандидата нельзя загрузить.
- Свежий прогон: 20 тестов прошли (API, адаптер, идентичность модели, парсер).
- Живой HTTP на localhost:8001 подтверждает base, query_adapter_enabled=false,
  правильный отбор SUP/бассейна/прогулок/еды с бюджетом и поиск похожих кофеен.
  Проверка — data/ml_fix_verification.json. Сохранённая OpenAPI обновлена.
- Compose config и git diff --check прошли. Docker-сборка и серверная нагрузка
  не проверялись. Backend, БД и исходные веса Qwen не менялись.
- Общая пригодность на всех естественных запросах по-прежнему не доказана:
  нужны независимая человеческая разметка, пользовательские реакции и новые намерения.
