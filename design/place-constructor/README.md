# Конструктор места: профиль и мини-профиль (прототип)

Интерактивный прототип UI/UX. Это **не часть приложения**: файл автономный, к API и БД не подключён.
Данные хранятся в `localStorage` браузера; фото — демо-иллюстрации с пометкой «ДЕМО».

- Открыть: `design/place-constructor/index.html` двойным кликом (нужен интернет только для шрифтов)
  или по адресу `/constructor/` на сайте — `vite build` копирует файл в `frontend/dist/constructor/`
  (плагин в `frontend/vite.config.ts`; в Docker-сборке с контекстом `./frontend` шаг пропускается).
  Страница помечена `noindex`.
- Проверить: `node design/place-constructor/qa.mjs` (Playwright из `frontend/node_modules`,
  скриншоты и лог — в `qa-output/`, папка в `.gitignore`).

## Объекты

| | Профиль (страница места) | Мини-профиль (карточка в ленте) |
|---|---|---|
| Что настраивается | фото, название, акцентное слово, описание, адрес; вид каждого блока | цвет карточки, смайлики, стикеры |
| Только чтение | категория (каталог), цена (проверенные данные) | главное фото и название — берутся из профиля |
| Пресеты | Классика · Море · Журнал · Ночной город · Тёплый вечер | Светлая · Бирюза · Песок · Ночь · Полароид |

## Модель взаимодействия

- **Просмотр / Редактирование** — переключатель в шапке. В просмотре нет панели и обвязки:
  ровно то, что увидит посетитель (скрытые блоки исчезают).
- **Выбор блока** — клик/тап по блоку или Enter на нём. Над выбранным блоком — ярлык
  `⋮⋮ Название ◉` (перетащить / скрыть). Esc — снять выбор.
- **Панель инструментов** справа (на телефоне — нижний лист). Без выбора: стиль страницы и список
  блоков. С выбором: «Содержимое → Цвет → Размер и положение → Показывать блок».
- **Перемещение** — перетаскивание за `⋮⋮` с подсветкой места вставки; альтернатива без мыши —
  стрелки ↑/↓ на ручке или кнопки «Выше/Ниже» в панели.
- **Отмена** — ↶/↷ и Ctrl+Z / Ctrl+Shift+Z; пресет применяется с подсказкой «Отменить — Ctrl+Z».
- **Главное фото** — звезда «★ Главное» в менеджере галереи и плашка
  «Главное фото · на карточке в ленте» на холсте; кнопка «☆ Сделать главным» у остальных.
  Удаление главного — главным становится следующее, пользователь получает предупреждение.

## Защитные ограничения (предложены вместо пустого пункта 5 брифа)

- **Цвета только из палитры** — 10 фонов и 5 цветов текста на основе токенов сервиса; свободного
  выбора цвета нет. Цвета текста с контрастом ниже 4.5 : 1 на текущем фоне перечёркнуты и
  недоступны; при смене фона нечитаемый текст автоматически переключается на «Авто».
  Акцентное слово получает акцент только при контрасте ≥ 3 : 1. Проверено скриптом: все пресеты
  и все 60 пар «фон × текст» проходят WCAG AA (минимум 4.72 : 1).
- **Размеры — три ступени** S / M / L вместо произвольных пикселей; ширина — «вся» или «половина».
  На телефоне блоки всегда во всю ширину.
- **Положение — по сетке**, а не свободно: блоки меняются порядком в 2-колоночной сетке, наложений нет.
- **Название нельзя скрыть**. Если видно только название — предупреждение.
- **Системный блок «Оценка и маршрут»** одинаков для всех мест и не настраивается.
- **Цена не редактируется владельцем**: по правилам каталога её подтверждает редакция
  (`price_rub`, дата проверки). Конструктор меняет только вид блока цены.
- **Тексты**: название ≤ 60, адрес ≤ 120, описание ≤ 1200 символов; разметка и ссылки не поддерживаются.
- **Фото**: JPG/PNG/WebP, ≤ 8 МБ, ≤ 12 штук; обязательное описание фото для незрячих перед отправкой.
  Понятные ошибки по каждому отклонённому файлу.
- **Модерация**: владелец «Отправляет на проверку», модератор «Публикует»; до публикации посетители
  видят прежнюю версию (согласуется с принципом «черновик → проверка → публикация»).

## Вес украшений (лимит 50)

| Вес | Смайлики | Стикеры |
|---|---|---|
| 5 | 🙂 😀 🌊 ☕ 🎨 🎶 | — |
| 10 | 😍 🔥 🌅 | Новинка · Вид на море · Тихо и уютно · Можно с детьми · Для свидания |
| 15 | ⭐ | Хит сезона |
| 20 | 💎 🏆 | Выбор редакции (только модератор) |

Счётчик «32 / 50» с полосой (бирюза → охра от 40 → графит на 50). Вес виден на каждом элементе.
То, что не помещается, неактивно (`aria-disabled`, подсказка «нужно 20, свободно 5»); нажатие
объясняет причину в live-регионе. На 50 — плашка «Лимит заполнен». Убрать элемент можно в
списке «На карточке» или кликом прямо по карточке. Стикеры — настроение, а не факты:
«бесплатно», часы и цены стикерами не заявляются.

## Расхождения со стилем кода

Прототип использует значения брифа: фон `#F6F7F5`, акцент `#157F8C`, засечка Source Serif 4.
В `frontend/src/styles.css` сейчас `#f7f8f5`, `#167d8d` и `Georgia`. Разница визуально мала;
при переносе в React стоит выбрать один источник истины.

## Что нужно для реализации в продукте

Прототип не меняет backend. Для настоящей функции потребуются: роль владельца места и права,
хранение фото (сейчас в проекте фото нет), поля `layout`/`card_style` у места с валидацией
палитры, весов и лимитов **на сервере**, очередь модерации и миграции Alembic.
