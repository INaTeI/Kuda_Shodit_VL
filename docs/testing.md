# Результаты локальной проверки

Проверено 12 ноября 2026 года.

- Docker-сборка runtime и test успешна, PostgreSQL 16.9.
- Миграция Alembic применена; alembic check: No new upgrade operations detected.
- pytest на реальной изолированной PostgreSQL: 33 passed (Linux/Docker, 6.85 с).
- Покрытие строк приложения по pytest-cov: 79%; seed исключён из измерения.
- Ruff: All checks passed.
- Docker Compose: docker compose config --quiet выполнен успешно.
- HTTP smoke: /docs, /openapi.json, readiness, категории, профиль, предпочтения,
  геофильтр, рекомендации, реакция, проверка ключа редактора и удаление профиля — успешно.
- В Swagger/OpenAPI 15 путей; количество методов больше, поскольку часть путей поддерживает несколько методов.
- В рабочую БД добавлены 8 демонстрационных категорий и 8 вымышленных мест.

Проверки покрывают публикацию/архивирование, валидацию координат/бюджета/категорий,
неизвестные цены, пагинацию, пустую выдачу, отсутствие доступа, изоляцию профилей,
обновление и отмену реакций, независимость знакомства от лайка, ranking и discovery.

Нагрузочные показатели и production SLO не измерялись. React-интерфейс не создавался,
проверки касаются API. Погода, фотохранилище, внешние карты и реальный каталог не подключены.

Скрипты-анализаторы навыка Docker запускались; часть замечаний эвристическая:
тестовые фиксированные ключи относятся только к изолированной test-db;
одноразовые migrate/tests не требуют постоянного healthcheck/restart;
healthcheck API наследуется из Dockerfile, сеть backend объявлена явно;
CMD в каждом отдельном этапе Dockerfile допустим. Итоговая проверка конфигурации — Docker Compose.

Повторить:

docker compose --profile test run --build --rm tests

docker compose --profile test run --rm tests ruff check --no-cache app tests

Фактически установленные runtime-версии сохранены в requirements-resolved.txt.
