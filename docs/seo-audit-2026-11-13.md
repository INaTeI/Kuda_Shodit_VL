## С чего начать

1. **Отдать содержательный HTML по публичным URL.** Принять работу по прямому GET главной, каталога и двух карточек, который уже содержит H1, текст и ссылки.
2. **Исправить HTTP-статусы и служебные файлы.** Принять работу по реальному `404` у неизвестного URL, валидным `robots.txt` и `sitemap.xml`, а также сохранённому переходу с HTTP на HTTPS за один шаг.
3. **Выпустить уникальные метаданные и canonical.** Включить их в тот же серверный HTML и проверить совпадение канонических URL со ссылками в каталоге и sitemap.

Пагинация — следующий шаг для обнаружения остальных карточек. Правку мобильной шапки и нормализацию вывода адреса можно сделать независимо от серверного рендеринга. После публикации исправлений проверить выбранные URL через Google Search Console и Яндекс Вебмастер.
